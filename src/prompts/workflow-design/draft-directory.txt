# Draft directory

- Create one complete directory containing `workflow.js` and every workflow-owned prompt, schema, fixture, or example it references.
- Use `{{draftRoot}}/<workflow-name>/` by default so authoring stays outside the project worktree.
- Call `propose_workflow` with the name. Omit `draftDir` for the default location; otherwise pass the directory path, never `workflow.js`.
- Proposal validation checks child capabilities and saves nothing on failure. Ensure every referenced resource exists before calling it.

```text
{{draftRoot}}/review/
  workflow.js
  prompts/review.txt
  prompts/synthesize.txt
```
