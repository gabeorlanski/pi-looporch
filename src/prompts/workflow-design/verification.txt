# Verification

- Add verification only when user-visible or artifact risk justifies another agent.
- Ask one decision question. Name every falsifiable check, source of truth, required evidence, and distinction between a failure and a recommendation.
- Prefer one voter. Return only the verdict and compact `mustFix` references consumed by repair; write detailed evidence to an artifact.
- On failure, pass the exact `mustFix` references to one repair stage, then run the same gate once.
- Select verifier `extensions` and `tools` intentionally; omission inherits workflow defaults.
- Skip optional verification when observed `budget.agentCount` or `budget.tokenCount` shows the run is already expensive.
