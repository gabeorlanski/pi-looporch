# Artifacts

- Write large generated content to named files. Every prompt that creates or consumes an artifact must state its exact path, format, ownership, and downstream use.
- Return `artifactPaths` plus the required status, decisions, summary, and evidence references; do not return full file contents when a later stage can read the file.
- Use `@workflow/...` with `readText` and `readJson` for workflow-owned prompts, schemas, fixtures, and small deterministic inputs. Use `writeText` and `writeJson` for artifacts and manifests that later stages read by path.
- Do not bulk-read project source merely to paste it into a prompt. Pass authoritative paths and state exactly what the child must inspect in them.
