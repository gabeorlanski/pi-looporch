# Artifacts

- Write large generated content to named files. State each artifact's path, format, ownership, and downstream use in the producing and consuming task.
- Return only the control fields a later stage reads, such as an artifact path, status, decision, stable ID, or short summary.
- Use `@workflow/...` with `readText` and `readJson` for workflow-owned resources. Use `writeText` and `writeJson` for generated artifacts and manifests.
- Pass project source by path and let the child read it. Copy source into a prompt only when the task must analyze that exact captured snapshot and no durable artifact already provides it.
