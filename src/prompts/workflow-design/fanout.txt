# Fan-out

- Select a bounded input set before fan-out. Record skipped scope and why it was excluded.
- Use `parallel(items, worker, { label })` only for independent items; use `pipeline(items, stages)` when each item needs the same ordered stages.
- Give every matching worker the same static task prefix and a small dynamic suffix containing only its item ID, path, or manifest entry.
- Preserve every worker artifact path or compact result in an explicit reducer manifest.
- `mapreduce` applies one capability selection to input selection, workers, and reduction. `verifier` does the same for voters and reduction.
- Workflow runs enforce `maxParallelAgents`; design fan-out as a bounded queue.
